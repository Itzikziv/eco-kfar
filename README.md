# CS Activity Day — הכפר הירוק

Projects built by our 10th–12th grade computer science students on the yearly CS activity day.
Each year has its own folder, its own Apps Script project and its own spreadsheet.

| Year | What was built |
|---|---|
| [2026](2026/) | An arcade of browser games + escape rooms, hosted on Google Apps Script |

## Starting a new year

1. Copy the previous year's folder (for example `2026/` → `2027/`).
2. In the new folder, remove the student games and rooms you don't want to keep,
   and empty the `GAMES` and `ROOMS` lists.
3. Create a new Apps Script project and put its script ID in the new folder's `.clasp.json`.
4. Follow the new folder's README. The old year keeps running as an archive.
